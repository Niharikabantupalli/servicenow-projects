# Implementation

## Activity 1: Creation of Table

### Objective

Create a custom table in ServiceNow to store database-related
records used in the application.

### Navigation

System Definition > Tables

### Steps

1. Navigate to **System Definition > Tables**.
2. Click **New**.
3. Fill in the table information:
   - **Label:** Database Tables
   - **Name:** u_database_table
4. Click **Submit**.

### Table Details

| Field | Value |
|---|---|
| Label | Database Tables |
| Name | u_database_table |

### Result

The custom table is created in ServiceNow.
